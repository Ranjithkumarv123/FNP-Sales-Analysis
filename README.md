# FNP-Sales-Analysis
Sales Analysis Dashboard using Microsoft Excel to analyze revenue, customer behavior, and product performance.
## 📌 Project Overview

This project analyzes sales data from Ferns N Petals (FNP) to uncover business insights, customer purchasing behavior, and product performance. An interactive Excel dashboard was created to help stakeholders make data-driven decisions.

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-selling products and categories
- Track monthly and seasonal sales trends
- Understand customer purchasing patterns
- Evaluate revenue and order performance

## 🛠️ Tools Used

- Microsoft Excel
  - Pivot Tables
  - Pivot Charts
  - Power Query
  - Slicers
  - Conditional Formatting
  - Dashboard Design

## 📊 Dashboard Features

- Total Revenue
- Total Orders
- Average Order Value
- Monthly Sales Trend
- Top Products
- Category-wise Sales
- Customer Analysis
- Interactive Filters (Slicers)

## 📈 Key Insights

- Identified high-performing products and categories.
- Analyzed monthly sales trends to determine peak sales periods.
- Evaluated customer purchasing behavior.
- Created an interactive dashboard for easy business reporting.
